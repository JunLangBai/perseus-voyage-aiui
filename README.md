# 英仙座远航

Rokid AIUI 单绿色眼镜策略 Demo，正式工程位于：

`F:\Github\AGnet\英仙座远航`

## 工程结构

- `app.json` / `app.js`：AIUI Agent 入口。
- `pages/index/index.ink`：完整单页游戏界面、AIUI 生命周期和镜腿按键处理。
- `game/engine.js`：资源、舰队、邮件、远征、战斗和本地存档规则。
- `interaction/gaze.js`：绝对方向四元数、偏航/俯仰平滑与 3DoF 视口运动。
- `interaction/gyroscope.js`：陀螺仪转头积分、焦点切换阈值与冷却。
- `interaction/temple.js`：镜腿滑动、单击、双击和兼容事件码的统一输入映射。
- `preview/`：与 AIUI 页面共享规则和样式的 Edge 预览，用于键位与布局验证。
- `dist/英仙座远航.aix`：唯一最新 AIX 交付包。

网页预览只是调试入口，不是正式交互实现。AIUI 页面本身已经监听眼镜输入事件。

## 3DoF 与镜腿操作

| 输入 | 行为 |
| --- | --- |
| 3DoF 转头 | 陀螺仪识别转头，切换上一项或下一项 |
| 3DoF 点头 | 执行当前焦点 |
| 3DoF 双击镜腿 | 返回上一级 |
| 平面上下滑 | 切换到上一个或下一个焦点 |
| 平面单击镜腿 | 执行当前焦点 |
| 平面双击镜腿 | 返回上一级 |
| `Backspace` | 3DoF 与平面模式均可返回 |

只有 `AbsoluteOrientationSensor` 和 `Gyroscope` 都产生有效读数后才进入 3DoF。
方向传感器负责页面和底部焦点轨道的环绕视差；陀螺仪三轴运动幅度负责识别“正在转头”，
方向传感器偏航方向决定上一项或下一项。一次转头累计约 5 度后切换一格，并带 320ms
冷却，避免一帧抖动连续跳项。点头通过 `onHeadGesture` 只确认当前焦点；点头产生的
俯仰变化不会切换左右焦点。

3DoF 中镜腿上下滑和单击确认会停用，只保留双击返回，因此不会出现点头与单击同时确认。
任一空间传感器不可用或报错时，界面切换到平面镜腿模式：上下滑选择、单击确认、双击返回，
点头确认同时停用。界面没有装饰圆环，底部焦点轨道本身就是可循环的 3DoF 环绕控件。

输入层兼容 `GlobalHook`、`Enter`、`SwipeUp`、`SwipeDown`、
`ArrowUp`、`ArrowDown`、`DoubleTap`、`DoubleClick` 和 `Backspace` 等宿主
事件名。两次单击在 360ms 内会合并为双击返回；单击会延迟 360ms 后再执行，
避免第一次点击被误当成确认。官方模拟调试会把一次“单击”同时派发为
`GlobalHook` 和 `Enter`，输入层会在 80ms 内将这一对别名合并为一次点击。

当前焦点使用 12% 绿色局部底色、全亮文字和底部文字提示；边框保持组件原有的
1px，不增加外轮廓或左侧粗线。页面根容器使用
`100vw × 100vh` 填满宿主模拟画布，主体使用 `scroll-view`；针对官方
`480 × 352` 横屏画布另有紧凑布局，同时保留 `360 × 480` 竖屏预览。

行星产出改为自动收获：页面可见时每 10 秒检查并领取一次，切回总览、重新进入页面或
从后台恢复时也会补收可结算的离线产出。总览只显示自动收获状态，不再提供
“征收产出”按钮或对应焦点项。

稳定度现在把行星产出系数调整为 0.6 至 1.4；科研值最高降低 32%
建造与维修成本；巨企好感满值时可降低 40% 贸易支付量。

殖民地日常维持默认开启：每颗己方行星每分钟基础消耗人口 2、能源 3、合金 2，
再乘以 0.6 至 1.4 的反向稳定度系数。稳定度越低，维持越贵；总览会显示当前
每分钟维持量，行星详情会显示该行星的稳定修正。主菜单可随时关闭该设置，
关闭后舰队维护仍照常结算。

科研系统只使用一个 0 至 100 的固定科研值，不再区分等级和进度。

强光模式使用 100% 绿色文字、加粗字形和更大的字号；480 × 352 横屏下
标题约 20px、行标题 15–16px、正文 12–13px。已在 AIUI Studio 的
“室内明亮”背景下验证。

自动收获区属于非交互信息，不再使用绿色填充或完整卡片边框，只保留上下分隔线。
它使用独立的 `harvest-status` 类，不继承可选项卡片样式。普通可选项保持 1px
边框；焦点只改变绿色底纹和文字亮度，不增粗边框，也不添加外轮廓或左侧标记。
`primary` 动作默认保持透明背景，只有获得焦点或按下时才显示强调色。

顶部四项资源使用固定 Grid：每格左侧为资源名、右侧为数值，四格基线一致，
不再依靠纵向 Flex 自动排版。

邮件详情中的选项一击即生效：选择“接受护航”或“维持警戒”后立即结算并返回
邮箱，不再显示额外的确认按钮或确认焦点。

页面已接入“领取、建造、邮件、地图、舰队、返回、攻击 + 行星名”的
`onVoiceWakeup` 文本路由；实际识别文本和真机唤醒链路仍待验证。

邮件详情默认聚焦第一项选择；星图底部提供“上一页”“下一页”“返回总览”。
主菜单提供“殖民地维持”开关和“退出游戏”，单击后立即保存；页面可见时另有
每 60 秒一次的独立自动存档。

## 本地预览

```powershell
cd F:\Github\AGnet\英仙座远航
npm run preview
```

打开：

`http://127.0.0.1:8765/preview/`

全新存档：

`http://127.0.0.1:8765/preview/?reset=1`

浏览器的 3DoF 模拟默认开启，鼠标移动控制环视，`←` / `→` 模拟陀螺仪换焦点；
附加 `flat=1` 可检查无传感器平面模式：

`http://127.0.0.1:8765/preview/?flat=1`

预览页用 `N` 模拟 3DoF 点头确认；平面分支用 `↑` / `↓` 选择、`Enter` 单击确认。
两种分支都支持双击返回和 `Backspace`。

## 官方 AIUI 预览与打包

单文件页面必须使用项目根路径导入共享样式：

```css
@import "/styles/app.css";
```

相对路径在普通浏览器中可以加载，但官方 Ink 运行时可能忽略。使用官方 CLI：

```powershell
npx --yes @yodaos-pkg/aix-cli check "F:\Github\AGnet\英仙座远航"
npx --yes @yodaos-pkg/aix-cli preview --dev "F:\Github\AGnet\英仙座远航"
npx --yes @yodaos-pkg/aix-cli pack "F:\Github\AGnet\英仙座远航" `
  -o "F:\Github\AGnet\英仙座远航\dist\英仙座远航.aix"
```

在 `https://aiui.rokid.com/` 的“代码”页中，通过项目“更多操作 →
`.aix导入`”载入打包文件，再到“模拟调试”选择 `page-英仙座远航`。

## 核心循环

**行星产出自动入库 → 建造舰队 → 查看星图 → 投入舰队远征 → 占领行星 → 获得更高产出**

目标是依次接管十颗行星。新存档从人口 137、能源 190、合金 127、舰船 10
开始；行星表中的基础产出为每分钟产量，页面内每 10 秒自动入库一次，离线最多累计
30 分钟。

推荐验证路线：

1. 选择潮汐-3。
2. 确认首轮产出已自动入账。
3. 进入舰队，连续建造五次扩充舰队。
4. 切换到星图第 2 页，确认上下页按钮左右横排。
5. 打开月镜港，把投入调整到 100 或以上。
6. 下滑镜腿移到“确认远征”，单击执行。
